# Maths — CM2 à 3e

PWA d'entraînement en mathématiques. Un seul site, 5 niveaux.

- **CM2, 6e, 5e, 4e, 3e** — 5 chapitres par niveau
- Chaque chapitre : **Leçon** (règles et formules) puis **8 exercices** générés
- Exercices à réponse libre (numérique) ou QCM selon le chapitre
- Suivi : XP, série, minutes, taux de réussite, chapitres maîtrisés
- Profil, export/import JSON, synchronisation GitHub Gist
- Hors-ligne après la première visite

## Installer
Safari → Partager → « Sur l'écran d'accueil ».
